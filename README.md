# project-init 🎀

The first group project from **Girls Who Code @ UTA**, built together at our weekly meetings! ✨

New to coding or GitHub? You're in the right place. No question is too small 💕

## 🌸 Getting Started

1. **Fork the repo** 🍴 A fork is your own copy of the project on GitHub, so you can make changes without needing special access.
   - Go to [github.com/utagwc/project-init](https://github.com/utagwc/project-init)
   - Click **Fork** (top right) → **Create fork**
2. Clone **your fork** to your computer (swap in your GitHub username):
   ```bash
   git clone https://github.com/YOUR-USERNAME/project-init.git
   cd project-init
   ```
3. Create a branch for your changes:
   ```bash
   git checkout -b add-your-name
   ```
4. Make your edits, then commit and push to your fork:
   ```bash
   git add README.md
   git commit -m "Add <your name> to contributors"
   git push origin add-your-name
   ```
5. Open a Pull Request (see below) 🫶

> 💡 **Staying up to date:** Before starting something new, go to your fork on GitHub and click **Sync fork** → **Update branch**, then run `git checkout main && git pull`.

## 💌 Submitting a Pull Request

A Pull Request (PR) asks the team to add your changes to the main project. Someone reviews it first, so don't stress about mistakes!

1. Go to [github.com/utagwc/project-init](https://github.com/utagwc/project-init)
2. Click the yellow **Compare & pull request** banner. If you don't see it, go to **Pull requests** → **New pull request** → **compare across forks**, then pick your fork and branch.
3. Give it a short title, like `Add Mariah to contributors`
4. In the description, say what you changed and why
5. Click **Create pull request** 🎉
6. Wait for a review. If someone asks for changes, edit your files, then commit and push to the same branch. The PR updates on its own ✨
